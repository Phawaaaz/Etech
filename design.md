    # AI Course Generator Landing Page Design System

This document defines the design system for a premium AI Course Generator.

## Philosophy
- Premium, minimal, trustworthy
- Consistent spacing and typography
- Reusable components only

## Grid
- Desktop container: 1280px
- Max content: 1200px
- 12 columns, 24px gutters

## Breakpoints
- 320
- 375
- 430
- 768
- 1024
- 1280
- 1440
- 1536

## Spacing Scale
4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96, 120, 160

## Border Radius
12, 16, 20, 24, 32, 9999

## Typography
Font: Satoshi (fallback: Geist, Manrope, Plus Jakarta Sans)

- Hero: 64/72
- H1: 48/56
- H2: 36/44
- H3: 24/32
- Body: 18/30
- Small: 16/24
- Caption: 14/20

## Colors
- Primary: #1565C0
- Primary Hover: #0D47A1
- Secondary: #42A5F5
- Accent: #FFB703
- Background: #F8FAFC
- Surface: #FFFFFF
- Border: #E2E8F0
- Text: #0F172A
- Muted: #64748B

## Section Order
1. Navbar
2. Hero
3. Logo Cloud
4. AI Features
5. How It Works
6. Templates
7. Categories
8. Testimonials
9. Pricing
10. FAQ
11. CTA
12. Footer

## Mobile
- 20px horizontal padding
- Single-column layout
- Hero: text → search → CTA → preview
- 64px section spacing
- Buttons full width

## Tablet
- 90% container
- Two-column grids
- Stacked hero

## Desktop
- Split hero
- 120px vertical section spacing
- 3–4 column grids

## Components
- Button
- Input
- Search
- Navbar
- Footer
- Feature Card
- Course Card
- AI Prompt
- Progress
- Pricing Card
- FAQ
- Testimonial
- CTA Banner

## Quality Checklist
- Use only spacing tokens
- One radius system
- One typography scale
- One color palette
- Reusable components
- Consistent hover/focus states
- Accessible contrast
